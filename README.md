# StorCard
StorCard is your own server for storing discount cards

## ENV параметры
Переменные среды для параметров сервера
### Обязательные параметры
#### SQL_DRIVER
Содержит параметр для выбора драйвера базы данных [sqlite, mysql, postgresql], по умолчанию sqlite
#### SQL_DB
Содержит параметр имени базы данных, по умолчанию storcard_db
#### PORT
Содержит порт на котором запустится сервер, по умолчанию 7000
#### ACCESS_TOKEN
Содержит время короткоживущего токена авторизации. Устанавливается в секундах, по умолчанию 3600
#### REFRESH_TOKEN
Содержит время долгоживущего токена авторизации. Устанавливается в секундах, по умолчанию 604800
### Необязательные параметры         
#### SQL_HOST
Содержит параметр хоста базы данных
#### SQL_PORT
Содержит параметр порта базы данных
#### SQL_USER
Содержит параметр пользователя базы данных
#### SQL_PASSWORD
Содержит параметр пароль пользователя базы данных
